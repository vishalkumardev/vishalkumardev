## 🚀 Featured Project: BuildShare.in

**[BuildShare](https://buildshare.in)** is a SaaS for distributing mobile app builds to testers and clients. It's a simple alternative to Firebase App Distribution, TestFlight, and Diawi.

- ⚡ Upload an APK/IPA and share an install link in seconds
- 🕶️ Anonymous uploads with 24-hour expiry, no signup needed
- 🧰 CLI tool (npm) and Fastlane plugin for CI/CD
- 🔗 Jira and Linear integrations
- 📲 iOS UDID auto-capture on paid plans
- ☁️ Bring your own storage (S3, GCS, Azure Blob) on the Team plan
- 💳 Free, Pro, and Team plans with Razorpay billing
- 📱 Companion tester app in React Native, with passwordless OTP, Google, and Microsoft sign-in
